# ASX Payroll React

React/Vite wrapper untuk sistem penggajian ASX yang dimigrasikan dari file HTML sumber tanpa mengubah tampilan utama.

## Menjalankan
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Firebase
Konfigurasi Firebase Realtime Database yang sudah ada pada file sumber dipertahankan. Data utama tetap tersinkron pada node:
`asx_payroll_system_v2`

## Rekapan Gaji JPG
Di tab **Rekap Gaji**, tombol **Rekapan Gaji** mengunduh JPG dengan format tabel rekap seperti contoh Agustus 2026.
